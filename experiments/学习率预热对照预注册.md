# 学习率预热对照：实验开始前记录

## 状态

## 问题与待验证的假设

从相同随机初始化和数据出发，学习率第 1 步直接从峰值开始并余弦下降，相比原来的 500 步预热再余弦下降，是否改变训练前期的 loss 波动，并且这种差异是否延续到第 10,000 步的验证 loss？

工作假设：预热可能减小训练前期的波动，使后续验证 loss 更低。竞争解释：无预热可能同样稳定，甚至前期下降更快；也可能前期有差异但后期差异变小。这是待检验的判断，不预设哪一组获胜。

- B：从 A 的第 0 步 checkpoint 分叉，运行 10,000 步，`warmup_steps=0`，第 1 步学习率 `0.0006`，其后按当前代码的余弦日程下降。

- B 继承该 checkpoint 中的模型参数、AdamW 优化器状态、NumPy 采样状态和 MLX 随机状态；不显式重置训练种子。

## 观察与判断

1. 主要结局：相同抽样验证口径下第 10,000 步的 validation loss；完整验证如需开展，必须对 A、B 使用同一个评测程序和相同口径。
2. 训练动态：记录每一步训练 loss 与学习率，查看第 1–500 步和第 501–1,000 步的轨迹；将前 500 步相邻训练 loss 差值的标准差及绝对差值最大值作为波动描述，同时保留完整曲线。单步 loss 还受批次内容影响，不把波动直接等同于梯度或参数更新不稳定。
3. 安全性：记录非有限 loss、数值错误及异常退出。当前写日志时禁止非有限数值；如果进程报错退出，按原始错误和最后记录分析，不伪装成正常结束。
4. 若 B 同样稳定或更快下降，或最终验证差异很小，应如实呈现并弱化假设；结果不如预期时先核对输入、checkpoint、学习率轨迹和评测口径，再考虑假设。单次配对无法代表所有随机种子。

## 已知限制

- 当前 `lr_for_step` 的余弦衰减长度取决于 warmup 长度。B 去掉 warmup 后，训练中后期的学习率也与 A 不完全相同；本实验比较的是两种完整日程，不能把差异严格归因于“仅前 500 步是否渐增”。
- 即使只调整前 500 步，渐增和峰值恒定的累计学习率也不同，不能仅凭两组识别具体作用机制。
- 原 A 组未记录梯度范数或逐步参数更新范数，不可声称两组这些指标已比较；后续如需要，应对两组重新采集同口径的数据。
- A 的验证集已排除与训练集完全相同的故事，但没有检查近似重复；抽样结果不是整体生成质量，也不是独立随机初始化重复实验。
- A 已中途在第 171 步安全保存后恢复，完整优化器和随机状态已保存；比较时需检查日志及恢复行为，不把主动中断描述为数值故障。
