# 训练动态实验预注册：数据覆盖与重复

## 状态

本文件在模型级对照训练和结果读取之前写下。尚未运行两组训练，也没有结果。

## 问题

从同一份本机训练 checkpoint 出发，固定后续处理的 token 预算，只改变可采样的训练数据池大小：更多不同训练文本，是否会使模型在独立验证集上的 loss 下降得更快？

## 假设及理由

在本次条件下，我预期较大的数据池相较小数据池更有利于降低验证 loss；较小数据池可能更快降低其被反复抽到的训练文本上的 loss，却不一定改善独立验证集。

理由是：较大的池子可能覆盖更多不同的故事和表达；固定预算下，小池子的相同片段更容易反复出现。但两组模型都有相同的先前训练经历，数据难度、顺序和随机采样也会影响结果，因此结果方向未知。

## 计划的单变量对照

- 共同父状态：同一份本机随机初始化、真实训练得到的 checkpoint，含模型参数和优化器；每对使用相同的新训练采样种子，验证种子固定。不使用作者发布的权重。
- A：只从训练 token 流的前 1,000,000 个位置取样。
- B：只从同一训练 token 流的前 10,000,000 个位置取样；包含 A 的数据。
- 两组保持一致：Tokenizer、模型、父状态、采样算法、后续 optimizer 设置、学习率计划、序列长度、微批次、梯度累积、更新次数和验证集。
- 计划每组新增 500 次优化器更新；如硬件限制要求更换微批次，须使两组微批次与梯度累积完全相同，并记录实际处理 token 数。固定 token 预算与固定原始故事覆盖无法同时做到，覆盖差异属于本研究的作用路径。
- 主要比较：同一独立验证集上的平均 next-token loss，按后续处理 token 数对齐；辅助记录训练 loss、速度以及训练池覆盖和采样重复情况。
- 计划使用训练采样种子 2027、2028、2029，各完成一组 A/B 配对；验证采样种子固定不变。三对均从同一个父 checkpoint 出发，因此只能衡量后续采样的变化，不能代表不同预训练初始化的全部不确定性。

## 结果不符合预期时的处理

1. 测量：复核评估数据、目标位移、token 分母、checkpoint 和数据池范围。
2. 设计：核对两组父状态、优化器、学习率、更新次数和输入处理是否一致；检查数据池故事的分布是否明显不同。
3. 假设：若测量和设计可靠但大池验证 loss 未改善或更差，记录结果并修正本条件下的假设，不挑选有利样例。

## 限制

本研究比较训练后期有限预算内的两个嵌套数据池，并不直接证明从随机初始化开始、不同语料或其他模型规模下的规律。历史训练可能已使模型接触部分池内样本，必须在结果中说明。
